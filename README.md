# WeDance — локальний багатосторінковий прототип, концепція 02

Оновлення від 8 листопада 2026 року на основі погодженого плану й коментарів щодо glassmorphism, щільності та анімацій. Статичний HTML/CSS/JS, без залежностей для перегляду. Контент сайту англійською, примітки до прототипу українською.

## Як переглянути

Відкрити `dist/index.html` у браузері. Усі дев’ять сторінок працюють через звичайні посилання, зокрема при прямому відкритті файлів. Шрифти, фотографії й відео локальні.

Або запустити з кореня проєкту:

```sh
python3 -m http.server 8080 --bind 127.0.0.1 --directory prototype/dist
```

Відкрити http://127.0.0.1:8080. Зупинка сервера: Ctrl+C.

## Візуальні зміни

- Напівпрозора округлена sticky-навігація, скляні відеокнопки, підписи фото й форма. Є blur для сучасних браузерів та читабельний базовий фон.
- Відступи секцій на desktop зменшено зі 110 до 64 px, на mobile — до 38 px. Картки, команда й форми стали компактнішими.
- Радіуси медіаблоків і карток 18–28 px, кнопки й перемикачі округлені.
- Плавна поява компонентів, делікатне масштабування фото, переходи навігації, фільтра та FAQ. Підтримка `prefers-reduced-motion`.
- Чорний / молочний білий / золотий, локальні Gloock і DM Sans, наявні матеріали WeDance.

Аналіз референсів і рішення: `DESIGN.md`. Результати перевірки: `VERIFICATION.md`. Скриншоти версії 02: `previews/v2-*.png`.

## Редагування

- `src/*.html` — спільні секції й шаблони головної.
- `build.mjs` — навігація, футер, контент внутрішніх сторінок і генерація HTML.
- `dist/styles.css`, `dist/app.js` — спільні стилі та інтерактивність, редагуються безпосередньо.
- `dist/assets/` — локальні медіаматеріали; оригінали з WordPress не змінюються.

Після змін шаблонів або контенту внутрішніх сторінок:

```sh
node prototype/build.mjs
```

Генератор перезаписує дев’ять HTML-файлів у `dist/`; CSS, JavaScript і медіа зберігає. Для самого перегляду Node не потрібен.

## Межі прототипу

Форма демонстраційна: локальна валідація та чесне підтвердження без надсилання чи зберігання даних. Вибір напряму переноситься у форму. Фільтр розкладу працює, зокрема за адресою `schedule.html?program=kids`.

Ціни, тривалість і розклад позначені як такі, що очікують підтвердження. Відгуки — підписані заглушки, без вигаданих рейтингів, авторів і цитат. Kids і Weddings мають фотографії до отримання відповідних відео. Факти про тренерів успадковано з попереднього прототипу та чинного сайту, остаточний текст очікує погодження.

Прототип має `noindex, nofollow`. Чинний WordPress не змінений. Публікація не виконувалась.

## Поточне оновлення: відео та анімації

Hero — мозаїка з трьох відеоплощин, світлого блоку бренду й центрального тексту, зі спільною паузою. Плашки Prototype / Design notes, Photo preview, Studio film та підпис-лічильник фото прибрано. Картки програм відтворюють inline-відео: перша при появі на екрані, інші при наведенні/фокусі або натисканні кнопки відтворення. Одночасно працює одна картка, поза екраном ролики зупиняються.

Секція про підхід на desktop закріплена протягом довшої ділянки скролу, а сцени змінюються не частіше ніж раз на 1,8 с. Mobile і reduced-motion використовують звичайний потік тексту. Деталі та обмеження медіаматеріалів — у `DESIGN.md` та `CONTENT.md`. Нові знімки: `previews/v4-*.png`.

## Два варіанти hero для вибору клієнтом

- `dist/index.html` — актуальний варіант: верхня ліва плитка з фото пари (`assets/adults.jpg`), інші відеоплитки збережені.
- `dist/index-hero-video.html` — попередній варіант мозаїки з відео у верхній лівій плитці.

Обидва файли — повні головні сторінки. Генератор зберігає обидва варіанти: поточний шаблон `src/hero.html`, попередній — `src/hero-video.html`. Скриншоти для порівняння: `previews/hero-option-*.png`.

## Gift Certificates і навігація

Додано `dist/gift-certificates.html` (шаблон `src/gift-certificates.html`). Сторінка доступна з desktop/mobile-меню й футера. Матеріали з https://wedance.studio/gift-certificates/: Bronze $100, Silver $250, Gold $500, довільна сума через звернення до студії, сертифікати для однієї людини чи пари та нових/чинних учнів. Кнопки пакетів ведуть на оригінальні Stripe checkout URL; платежі у прототипі не виконувалися. Умова про 30 днів перенесена з джерела без зміни формулювання. Форма запиту залишається локальною демонстрацією.

Кнопку Your first lesson прибрано з хедера всіх сторінок. Стрілка Programs — SVG-chevron з вирівнюванням і поворотом при відкритті меню. Вступ до програм має контрольовані смислові рядки без окремого слова bigger на desktop.

## Відео для швидкого перегляду

У `dist/assets/video/` — оптимізовані H.264 MP4: 24 fps, faststart, desktop до 960 px і mobile до 480 px по довшій стороні. Повний ролик студії збережено для діалогу, фонові hero/coaching-прев’ю обмежені 12 секундами. Джерела не перезаписуються. Для повторної оптимізації потрібні локальні оригінали з `dist/assets/` та FFmpeg (або Python-пакет imageio-ffmpeg):

```sh
python3 scripts/optimize-media.py
```

Розміри всіх результатів: `MEDIA-REPORT.json`. Два поточні hero-відео: 7 417 023 → 856 419 байтів desktop / 232 600 байтів mobile. Обидва WebP-постери разом — 23 906 байтів.

Використано підхід із vio-landing: постер до запуску, preload=none, відкладений старт після першого рендеру/idle, запуск лише видимих відео й пауза поза екраном. Початкові запити hero рознесені в часі. На мобільних і повільному зв’язку вибирається менший MP4; Save-Data та reduced-motion не запускають відео автоматично. Картки завантажуються лише за потреби, діалоги — після натискання.
